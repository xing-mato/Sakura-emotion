# 情绪池 · Sakura 插件

给角色一套**以「轮」为节拍**的情绪：她每回完一句话，由模型决定这一轮该往哪几根弦上加多少、
减多少。她从二十五种情绪里挑出「主·次·辅」三根表现出来，另外三根留作不表现的余韵，
用百分比显示在左侧栏的「情绪」页。时间不参与计算，只在"很久没说话"时作为一条事实递给模型。

---

## 一、它解决什么

Sakura 原本的情绪是**每一轮临时推出来的**：模型读一遍人设和最近几轮对话，决定这句话用什么语气。
于是出现三种体感：

| 你看到的 | 实际发生的事 |
| --- | --- |
| 上一轮还在生气，下一轮发个表情包她就笑着接话 | 情绪**没有残留** |
| 一句话把她推到底，之后一直挂在那儿 | 情绪**没有回落** |
| 中间那层"有点闷、但还没生气"根本不存在 | 情绪**没有强度** |

这个插件补的就是那个"状态"：二十一根弦里此刻在場的主·次·辅、0~100 的百分比、只在判断时变。

---

## 二、怎么做到的（v2）

### 1. 以轮为单位，不是以秒

    她回复完成
      → 读回这一轮：你说的原话、她的回复、距上一轮多久
      → 一次模型判断
      → 稀疏增减值落到池子里（"委屈 +24、失望 +10"，没提到的就是没变）
      → 下一轮注入的就是新值

没有半衰期、没有 ticker、没有"读一次掉一点"。**状态只在判断时变。**

为什么不做时间衰减：Sakura 不是人。她没有一个持续运行的时间感，两次对话之间她实际上是"不存在"的——
没有经历，就没有淡忘的理由。而衰减会把"上一轮刚受的委屈"稀释成"她好像没那么在意"，
这恰恰是"情感欠缺"的来源。

### 2. 时间只在缺席时有意义

判断的输入里有一行「上一轮至今：72 小时」。加多少生气、要不要委屈、还是只是淡淡一句"你终于来了"，
**由模型按她的人设决定**——"三天没来"和"三周没来"该有多生气，是性格问题，不该由插件常数决定。

### 3. 判断契约

    {
      "deltas": {"委屈": 24, "失望": 10}    ← 百分点，稀疏，单轮上下限 ±60
      "summary": "被放了鸽子，堵着"          ← ≤20 字，写进提示词
      "gist": "他说好陪她，又要走"           ← ≤24 字，进涟漪表
    }

判断失败（没配模型、请求失败、JSON 坏了）就**这一轮不动**——绝不退回关键词猜一个数顶上。

### 4. 涟漪

一次增减 ≥20 个百分点就留一条记录：什么时候、因为哪句话、哪根弦、动了多少。
最近两条会写进提示词，剩下的在设置页的「情绪涟漪」表里。

---

## 三、她看到的是什么

标准档（约 90 字）：

    【情绪】主·委屈 46%，次·无奈 22%，心境：等了一小时，心里发凉却还撑着。
    （这是你此刻的底色，不是台词：主决定这一轮的语气和取舍，次只影响措辞，辅几乎不表现；
    别把它念出来，让它从语气里透出来。强度低的时候宁可不表现，也别为了演而演。）

**为什么只有三个位置**：人在某一刻通常是一根主、最多再有一根次、偶尔一点辅。三根以上同时在场，
不是假的，就是自相矛盾的——那会让她既温柔又委屈又傲娇，除了「难以言喻」没有别的结果。
所以容量就是三个名额（state.MAX_MOOD）：名册外的情绪一律清零，谁进谁出由模型点名，
插件只负责「三」这个数，不替她判断该有谁。

平静时：

    【情绪】此刻没有哪根弦在被拨动，心境：平稳。
    （平静不等于冷淡，也不是没有脾气。）

详细档再加"最近的涟漪"与 Mem0 里的"相关往事"。

写这段文字只有一条硬规矩：**给行为，不给形容词**。"话变短、容易多想、等着被发现"会让她真的那样说话；
"你现在很委屈"只会被演成台词。三档措辞在 emotion_pool/taxonomy.py，可以直接改。

如果她的角色配置里允许语气标签（比如 中性/不满/害羞/请求/惊讶），
详细档会提醒模型让分段的 tone 跟着情绪走——TTS 和立绘会跟着变。

## 四、设置

设置 → 插件 → 情绪池。**没有任何一个输入框能改她的情绪值。**

| 设置 | 默认 | 作用 |
| --- | --- | --- |
| 让她有自己的情绪 | 开 | 总开关；关掉后不再注入也不再判断，状态原样保留 |
| 写进提示词的详细程度 | 标准 | 极简 / 标准 / 细致，只影响长度 |
| 和 Mem0 长期记忆联动 | 关 | 不联动 / 只读 / 只写 / 读写 |
| 保留多少条情绪涟漪 | 16 | 记录表与"最近的涟漪" |

按钮只剩三个：

设置页只留一个无害的按钮：**测试长期记忆桥**。

「清零」和「导出运行日志」搬到了左侧栏那个「情绪」页的底部（仪表盘右下角），
因为**那里是我们自己的 UI，能弹真正的对话框**；设置页的按钮只能回一行字，
看不见就会被当成坏了、再点一次——两次点击等于没拦。

在仪表盘里点「清零」会弹：

    ┌ 清空当前情绪？ ─────────────────┐
    │ 不推荐这么做，但这由你。清零会把 │
    │ 此刻的情绪值全部归零；涟漪记录和 │
    │ 聊天记录都还在。                │
    │              [取消]  [确认清零] │
    └─────────────────────────────────┘

「导出日志」同理，对话框里先说明会包含聊天记录、可能含隐私。
- **测试长期记忆桥** —— 检查能不能通过工具目录找到 Mem0。

「看一眼她现在的内心 / 打开完整预览 / 打开状态文件」三个按钮已经删掉：
它们在设置页里解决的是一个已经有别处解决的需求（面板 + 状态文件本身就能看）。

v1 里那四个数字（反应强度、消退速度、最短保持、切换门槛）全部删了——它们是把工程参数甩给用户，
而且互相耦合，没人调得动；情绪怎么变本来就该是模型的判断。

## 五、仪表盘

装好启用后，**Sakura 设置页的左侧栏「行为」组里会多出一个「情绪」入口**（插件自己注册的一页）：

    主  委屈   ███████████─────────────────   46%
    次  无奈   █████────────────────────────   22%
    辅  —      ────────────────────────────     —
    ▸ 其余 19 种
    ──────────────────────────────────────────────
    上一次判断：2 分钟前 · 委屈 +8                 [刷新]

点开那行「其余 19 种」：

    主  委屈   ███████████─────────────────   46%
    次  无奈   █████────────────────────────   22%
    辅  —      ────────────────────────────     —
    ▾ 其余 19 种
       喜悦  ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄   0%
       爱慕  ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄   0%
       ……（其余同理）
    ──────────────────────────────────────────────

- **在场的那三根摆在上面**，只有名字、条、百分比。「主」那行加粗——它决定这一轮的语气。
- **当前没有的情绪收进抽屉**：默认不占地方，点箭头才展开。展开后是二十一种的目录，
  它们此刻都是 0%——不是为了看数字，是为了知道池子里有哪些词。
- 平静时三个位置都是 **—**，抽屉里是全部二十一种。
- 真正的圆角胶囊条：8px 高、两端全圆、渐变填充。颜色跟情绪的分组走：
  暖（喜悦/爱慕/温柔/好奇/自信/害羞）、钝（无奈/无语/疑惑/尴尬/惊讶）、
  冷（委屈/失望/悲伤/生气/害怕/厌恶/担忧/孤独）、混（吃醋/傲娇）；抽屉里的条是虚线空槽。
- 只读，**不可拖动**。随手拨她的情绪这件事不该存在。
- 「刷新」= **请模型按最近 16 轮对话重新判断一次**（最多改三根），按钮会变成「想一想…」，等它回来。
